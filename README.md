# 일본 여행 기록장

가고 싶은 일본 여행지와 다녀온 곳을 지도 위에 기록하는 개인용 웹사이트입니다.

## 여는 법

- **PC**: `index.html`을 더블클릭하면 브라우저(Chrome 또는 Edge 권장)에서 열립니다.
- **휴대폰**: 아래 ‘휴대폰과 PC에서 같이 쓰기’대로 GitHub Pages에 올린 웹 주소(`https://아이디.github.io/japan-travel/`)로 엽니다.

지도와 장소 검색을 쓰려면 인터넷이 연결되어 있어야 합니다. 기록하기는 인터넷이 끊겨도 됩니다.

## 할 수 있는 것

- **가고 싶은 곳**: 기대도(♥), 가고 싶은 이유, 예상 비용(엔, 원화 환산 함께 표시), 가는 방법, 기타 메모
- **다녀온 곳**: 방문일, 만족도(★), 한 줄 평, 후기, 실제 쓴 비용, 재방문 의사, 다음을 위한 팁
- 가고 싶은 곳에서 **✓ 다녀왔어요!**를 누르면 다녀온 곳으로 옮겨집니다. 가기 전 메모는 그대로 남아서 기대와 실제를 나란히 볼 수 있습니다.
- 지역·카테고리·검색어로 목록 걸러 보기, 기대도순·만족도순·지역순 등으로 정렬하기
- 장소마다 **구글 지도에서 열기**와 **길찾기** 버튼
- **구글 지도에서 찾기**: 장소 추가·수정 화면의 이름 아래 버튼을 누르면 그 이름으로 구글 지도가 열립니다. 찾은 장소의 주소창 링크를 ‘구글 지도 링크’ 칸에 붙여넣으면 위치가 잡힙니다.
- **사진 넣기**: 장소 추가·수정 화면의 ‘사진’ 칸에서 한 곳에 10장까지 넣을 수 있습니다(휴대폰은 카메라·앨범 선택). 사진은 긴 변 1280px로 줄여 이 기기에 먼저 저장되고, 동기화를 켜 두면 사진마다 내 GitHub 비공개 Gist가 하나씩 만들어져 다른 기기에서도 보입니다. 인터넷이 없을 때 넣은 사진은 연결되면 자동으로 올라갑니다. 사진은 백업 파일(.json)에는 들어가지 않으니, 동기화를 켜 두는 것을 권합니다.
- **무료 자료로 빈 칸 채우기**(선택): 수정 화면의 ✨ 버튼을 누르면 OpenStreetMap·위키백과에서 사진·소개·홈페이지·가까운 역 등을 찾아 빈 칸만 채웁니다. 자료가 없는 곳이 많습니다.
- **기기 간 동기화**: 휴대폰과 PC에서 같은 기록 보기 (GitHub 계정 필요, 아래 참고)

## 장소 추가하는 방법

| 방법 | 하는 법 |
| --- | --- |
| 지도 클릭 | 지도에서 원하는 곳을 클릭한 뒤 ‘가고 싶은 곳’ 또는 ‘다녀온 곳’을 고릅니다. |
| 구글 지도 링크 | PC 구글 지도에서 장소를 누르고 주소창의 링크를 복사해 지도 위 검색창에 붙여넣습니다. 이름과 정확한 위치가 함께 들어옵니다. |
| 구글 지도 좌표 | 구글 지도에서 원하는 지점을 오른쪽 클릭하면 맨 위에 나오는 좌표(예: `34.96714, 135.77267`)를 눌러 복사한 뒤 붙여넣습니다. |
| 장소 이름 | 검색창에 이름을 입력합니다. 한국어로 안 나오면 일본어나 영어로 검색해 보세요. |

휴대폰 구글 지도 앱의 공유 링크(`maps.app.goo.gl/…`)에는 위치 정보가 없어서 바로 읽을 수 없습니다. 링크 앞에 장소 이름이 붙어 있으면 그 이름으로 대신 검색하고, 고른 장소에 링크도 함께 저장합니다.

## 휴대폰과 PC에서 같이 쓰기 (처음 한 번만)

기록은 각 기기의 브라우저에 먼저 저장되고, 동기화를 켜면 **내 GitHub 계정의 비공개 Gist** 한 곳과 자동으로 맞춰집니다. 서버를 따로 빌리거나 돈을 낼 필요가 없습니다.

### 1. 사이트를 웹 주소로 올리기 (GitHub Pages)

1. [github.com](https://github.com)에 가입하거나 로그인합니다.
2. 오른쪽 위 **+ → New repository**를 누르고 이름을 `japan-travel`로 적은 뒤 **Public**을 그대로 두고 **Create repository**를 누릅니다. (무료 GitHub Pages는 공개 저장소에서만 됩니다. 올라가는 건 사이트 코드뿐이고 여행 기록은 올라가지 않습니다.)
3. 저장소 화면의 **uploading an existing file** 링크를 누르고 `index.html`, `style.css`, `app.js` 세 파일을 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
4. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 고르고 **Save**를 누릅니다.
5. 1~2분 뒤 같은 화면 위쪽에 `https://아이디.github.io/japan-travel/` 주소가 나옵니다. 이 주소가 휴대폰에서 쓸 주소입니다.

나중에 사이트 코드가 바뀌면 3번처럼 세 파일을 다시 올리면 됩니다. 기록은 그대로 남습니다.

### 2. 기존 기록이 있는 PC에서 먼저 동기화 켜기

지금까지 `index.html`을 더블클릭해서 쓰던 기록은 그 브라우저 안에만 있습니다. **그 화면에서 먼저 연결해야** 기존 기록이 GitHub으로 올라갑니다.

1. 평소처럼 `index.html`을 더블클릭해서 엽니다.
2. 오른쪽 위 **백업·설정 → 기기 간 동기화**에서 **GitHub 토큰 만들기 ↗**를 누릅니다. GitHub 화면이 `gist` 권한만 체크된 채로 열립니다.
3. Expiration(만료일)을 여행이 끝난 뒤로 고르고 맨 아래 **Generate token**을 누른 다음, 나온 `ghp_…` 토큰을 복사합니다. (이 화면을 벗어나면 토큰을 다시 볼 수 없으니 바로 붙여넣으세요.)
4. 사이트로 돌아와 토큰을 붙여넣고 **연결**을 누르면 “이 기기의 N곳을 GitHub에 올렸어요”가 뜹니다.

### 3. 휴대폰에서 연결하기

1. 휴대폰 브라우저에서 1번의 웹 주소를 엽니다. (iPhone은 Safari 공유 버튼 → **홈 화면에 추가**, 안드로이드는 Chrome 메뉴 → **홈 화면에 추가**를 해 두면 앱처럼 열 수 있습니다.)
2. **백업·설정 → 기기 간 동기화**에서 토큰을 붙여넣고 **연결**합니다. 휴대폰에서 GitHub에 로그인해 같은 링크로 토큰을 하나 더 만들어도 되고, PC의 토큰을 메신저 ‘나에게 보내기’ 등으로 옮겨도 됩니다.
3. PC의 기록이 그대로 나타나면 끝입니다.

PC에서 웹 주소로 열어 쓰고 싶다면 그 화면에서도 한 번 연결하면 됩니다. (파일로 연 화면과 웹 주소로 연 화면은 브라우저 저장 공간이 따로라서 각각 연결해야 합니다.)

### 동기화는 이렇게 움직입니다

- 고치면 이 기기에 바로 저장되고, 1~2초 뒤 GitHub에 올라갑니다.
- 앱을 열 때, 다른 앱을 쓰다 돌아올 때, 인터넷이 다시 연결될 때, 켜 둔 동안 3분마다 다른 기기의 변경을 받아옵니다.
- 두 기기에서 같은 장소를 고쳤다면 **나중에 고친 쪽**이 남습니다. 지운 장소는 다른 기기에서도 지워집니다.
- 상태 표시: PC는 화면 위쪽 알약, 휴대폰은 ‘백업·설정’ 옆의 점입니다. 초록=동기화됨, 파랑 깜빡임=맞추는 중, 노랑=오프라인(기기에는 저장됨), 빨강=오류(백업·설정에서 이유 확인).
- GitHub의 Gist는 바뀔 때마다 이전 버전을 남기므로, 실수로 지운 기록도 **백업·설정 → GitHub에서 보기 ↗ → Revisions**에서 찾을 수 있습니다.
- 토큰이 만료되면 빨간 점과 함께 안내가 나옵니다. 새 토큰을 만들어 **연결 끊기 → 다시 연결**하면 됩니다.

### 보안 메모

- 토큰은 각 기기 브라우저에만 저장되고 GitHub(api.github.com)과 통신할 때만 쓰입니다. `gist` 권한만 있어서 저장소나 계정 설정은 건드릴 수 없습니다.
- 비공개(secret) Gist는 검색이나 프로필에 나오지 않지만, 주소를 아는 사람은 열어 볼 수 있습니다. Gist 주소를 남에게 공유하지 마세요.
- 휴대폰을 잃어버리면 [github.com/settings/tokens](https://github.com/settings/tokens)에서 그 토큰을 **Delete**하세요.

## 데이터 백업

- 동기화를 켜지 않았다면 기록은 **지금 쓰는 브라우저 안에만** 저장됩니다. 브라우저 데이터를 지우면 함께 사라지니, **백업·설정 → 파일로 내보내기**로 가끔 백업해 두세요.
- 백업 파일은 **파일 가져오기**로 다시 불러올 수 있습니다(기존 기록과 합쳐짐, 같은 장소는 파일 쪽 내용으로 바뀜). 동기화를 켜 둔 상태에서 가져오면 다른 기기에도 그대로 퍼집니다.
- 동기화 대신 파일로 기존 기록을 옮겨도 됩니다: 예전 화면에서 **파일로 내보내기** → 새 화면(웹 주소)에서 **파일 가져오기**.

## 파일 구성

- `index.html`: 화면 구조
- `style.css`: 디자인
- `app.js`: 지도, 구글 지도 링크 해석, 기록 저장, GitHub Gist 동기화

## 사용하는 무료 서비스

- 기본 지도: [OpenFreeMap](https://openfreemap.org) 벡터 지도(OpenStreetMap 데이터). 가입·API 키·이용 한도 없이 무료이고, 지도 오른쪽 아래 출처 표시만 지키면 됩니다. 한국어 이름이 등록된 지명은 한국어로 보입니다.
- 산 음영과 다른 지도: 일본 국토지리원 지도 타일(무료, 출처 표시). 지도 오른쪽 위 버튼에서 ‘연한 지도’, ‘표준 지도’로 바꾸거나 산 음영을 끌 수 있습니다. 웹 주소로 열었을 때는 OpenStreetMap 지도도 고를 수 있습니다(파일로 바로 열면 OpenStreetMap이 지도 이미지를 막아서 목록에서 빠집니다).
- 장소 검색·주소 찾기: OpenStreetMap Nominatim. 무료 공용 서버라서 검색은 필요할 때만 합니다.
- 사이트 주소: GitHub Pages / 기기 간 동기화: GitHub Gist (둘 다 무료)
- 구글 지도 API는 쓰지 않습니다. API 키나 결제 등록 없이 동작합니다.
