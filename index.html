        기기 간 동기화

        휴대폰과 PC에서 같은 기록을 보려면 GitHub 계정으로 동기화를 켜세요. 기록은 내 GitHub의 비공개 Gist 한 곳에 보관되고 기기에도 남아서, 인터넷이 끊겨도 계속 쓸 수 있어요.

        1. GitHub 토큰 만들기 ↗를 열면 gist만 체크돼 있어요. Expiration(만료일)을 여행 뒤로 고르고 맨 아래 Generate token을 누르세요.
        2. 만들어진 ghp_… 토큰을 복사해 아래에 붙여넣고 연결을 누르세요.
        3. 휴대폰에서도 이 사이트를 열고 똑같이 연결하면 끝이에요. 휴대폰에서 토큰을 하나 더 만들어 써도 돼요.

        이 기기에 있던 기록은 연결할 때 GitHub의 기록과 합쳐져요. 지금까지 index.html을 더블클릭해서 쓰던 PC라면, 그 화면에서 먼저 연결하면 기존 기록이 그대로 올라가요. 토큰은 이 기기 브라우저에만 저장되고 GitHub과 통신할 때만 써요.

        GitHub와 동기화 중
        GitHub에서 보기 ↗

        고친 내용은 몇 초 안에 올라가고, 앱을 다시 열거나 화면으로 돌아올 때 다른 기기의 변경을 받아와요. GitHub의 Gist에는 바뀔 때마다 이전 버전이 남아서 실수로 지워도 되찾을 수 있어요.

        데이터 백업

        기록은 이 브라우저에 먼저 저장돼요. 동기화를 켜지 않았다면 브라우저 데이터를 지울 때 함께 사라지니 가끔 파일로 내보내 두세요. 동기화를 켜기 전에 다른 브라우저에 쌓아 둔 기록도, 그쪽에서 내보낸 파일을 여기서 가져오면 합쳐져요.

        가져오면 지금 기록과 합쳐져요. 같은 장소가 있으면 파일 쪽 내용으로 바뀝니다.

        사용법

        구글 지도에서 가져오기

        1. 링크 붙여넣기 (PC 추천) 구글 지도에서 장소를 누른 뒤, 브라우저 주소창의 링크를 통째로 복사해서 지도 위 검색창에 붙여넣으세요. 이름과 정확한 위치가 함께 들어와요.
        2. 좌표 붙여넣기 구글 지도에서 원하는 지점을 마우스 오른쪽 버튼으로 누르면 메뉴 맨 위에 좌표(예: 34.96714, 135.77267)가 보여요. 누르면 복사되니 그대로 붙여넣으면 돼요.
        3. 휴대폰 공유 링크 maps.app.goo.gl로 시작하는 짧은 링크에는 위치가 들어 있지 않아서 바로 읽을 수 없어요. 링크를 브라우저에서 한 번 열고 바뀐 긴 주소를 붙여넣거나, 장소 이름으로 검색해 주세요. 짧은 링크도 장소에 저장해 둘 수는 있어요.

        이 지도에서 바로 추가하기

        1. 지도 클릭 원하는 곳을 클릭하고 ♡ 가고 싶은 곳 또는 ✓ 다녀온 곳을 고르세요.
        2. 이름 검색 검색창에 장소 이름을 입력하세요. 한국어로 안 나오면 일본어나 영어로 찾아보세요. (예: 清水寺, Kiyomizu-dera)

        기록하기

        가고 싶은 곳에는 기대하는 이유, 예상 비용, 가는 방법을 적어 두세요. 다녀온 뒤 ✓ 다녀왔어요!를 누르면 ‘다녀온 곳’으로 옮겨지고, 가기 전 메모는 그대로 남아서 기대와 실제를 나란히 볼 수 있어요.

        저장과 동기화

        기록은 이 기기 브라우저에 바로 저장돼요. 백업·설정 → 기기 간 동기화를 켜면 내 GitHub 계정에도 보관돼서 휴대폰과 PC에서 같은 기록을 볼 수 있어요. 인터넷이 끊긴 동안 쓴 기록은 다시 연결되면 자동으로 맞춰져요. 화면 위쪽(휴대폰은 ‘백업·설정’ 옆 점)의 초록색이 ‘동기화됨’이에요.
